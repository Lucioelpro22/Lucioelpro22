## Engineering principles

```text
least privilege      explicit policy       human accountability
fail closed          privacy by design     observable decisions
secure defaults      local-first data      documented limitations
```

My security and AI projects are intentionally defensive. They do not enable unauthorized access, covert monitoring, automatic retaliation, or unreviewed high-impact actions. Where automation could create harm, the system records a proposed action and requires explicit, auditable approval.

## How I work

1. Define the problem, threat model, and safety boundary.
2. Build a small, testable core with deterministic behavior.
3. Validate with tests, static analysis, dependency checks, and CI.
4. Document setup, limitations, privacy behavior, and failure modes.
5. Release incrementally and keep consequential actions human-controlled.
